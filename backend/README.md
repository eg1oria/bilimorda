# Bilimorda API

NestJS API для регистрации пользователей, управления версиями теста, сохранения
ответов и внутренней админки.

## Локальный запуск

1. Скопируйте `.env.example` в `.env` и замените `ADMIN_API_KEY` длинной случайной строкой.
2. Выполните `npm install`.
3. Примените миграции: `npm run db:deploy`.
4. Запустите API: `npm run start:dev`.

По умолчанию API слушает только `127.0.0.1:3001`. Относительный SQLite-путь из
`DATABASE_URL` считается от `prisma/schema.prisma`; файл должен находиться на
постоянном диске и регулярно копироваться.

Команды миграции автоматически создают отсутствующий SQLite-файл и его каталог
перед запуском Prisma.

## Команды

- `npm run db:migrate -- --name <name>` — создать миграцию при разработке.
- `npm run db:deploy` — применить готовые миграции.
- `npm run test` — unit-тесты.
- `npm run test:e2e` — e2e с отдельной временной SQLite-базой.
- `npm run build` — production-сборка.

## Система вопросов

- Рабочий список вопросов редактируется через защищённый `/api/admin/questions`.
- Публикация создаёт неизменяемую версию; новые попытки используют последнюю
  версию, а начатые продолжают свою.
- До первой публикации регистрация сохраняет пользователя и возвращает
  `testAvailable: false`.
- Токены попыток возвращаются только при регистрации, а в SQLite сохраняются в
  виде SHA-256-хеша.

После обновления production-кода сначала примените `npm run db:deploy`, затем
создайте в админке полный набор вопросов и опубликуйте первую версию.
